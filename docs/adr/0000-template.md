# ADR-0000: Title, as a decision rather than a topic

- **Status:** Proposed | Accepted | Superseded by [ADR-XXXX](.) | Deprecated
- **Date:** YYYY-MM-DD
- **Deciders:**

## Context

What is true that forces a choice. Constraints, the thing that broke, the thing
that would break. This section should be checkable by somebody who disagrees with
the decision.

## Decision

What was decided, in the active voice and in one or two sentences. Not "we should
consider" — a decision that has not been taken does not need a record.

## Consequences

What follows, including the parts that are worse. An ADR listing only advantages
is a sales document; the value of the format is that it is honest about the price.

## Alternatives considered

What else was on the table and why it lost. **This is the section that pays for
the whole document** — a year from now the question is not "what did we do" (the
code says that) but "did we think about X". Name the alternative even when the
answer was obvious at the time; obvious ages badly.
